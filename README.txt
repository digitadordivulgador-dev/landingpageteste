SaúdeViva Prime - Landing Page Premium

Arquivos incluídos:
- index.html
- style.css
- script.js
- pasta images/ com as imagens geradas por IA

Como usar:
1. Extraia o arquivo .zip
2. Abra o arquivo index.html no navegador para visualizar
3. Publique a pasta em um serviço como Netlify, Vercel ou GitHub Pages

Observação:
O Google Sites não publica HTML/CSS/JS como site nativo.
Para usar no Google Sites:
- hospede esta landing page externamente
- depois use a opção Incorporar (Embed) no Google Sites
